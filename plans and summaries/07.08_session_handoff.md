## Decisions locked + what shipped
- **Change A — `AttentionDensityHead`** (`src/model.py`): cross-patch self-attention (`nn.TransformerEncoder`)
  inside the density head, still 100% behind the existing stop-gradient boundary. Opt-in via
  `model.density_head_type: "mlp"|"attention"`; `"mlp"` branch kept byte-identical (same state-dict keys) so
  old checkpoints are unaffected.
- **Change B — windowed E9 concentricity loss**: `compute_polar_grid` now also returns `theta_grid`;
  `density_concentricity_loss` gained an angle-windowed variant using circular distance
  (`atan2(sin Δθ, cos Δθ)`), correctly handling the 0°/360° seam. Opt-in via
  `model.density_concentricity_window_deg` (`null` = old global behaviour, unchanged).
- **Change C — "pierwsze półrocze −1"**: for BITS1q/BITS2q campaign catches, effective age (used by BOTH
  CORAL and the density head) is reduced by 1, per the user's explicit choice to scope it to both heads, not
  density-only. Opt-in via `data.quarter_age_adjustment_enabled`. Explicitly the *not* safe-by-construction
  change of the three — it changes CORAL's own supervision target for ~40.2% of the labeled set and needs a
  real training run to validate, not just tests.
- New config `configs/config_attention_first.yaml` (all three flags on, heavily commented in Polish) and
  launcher `main_attention_first.py` (mirrors the `main_e9.py` pattern). Both verified via `load_config()` /
  `--dry-run`, never actually committed by me — **discovered this session that they're already committed**
  (commits `54bed80 nowa głowica`, `44cb37b main_attention_first.py`), but neither carries a
  `Co-Authored-By: Claude` trailer and the git author differs between the two, so these were almost certainly
  committed by the user directly, outside this session — not a violation of the earlier "nic nie komituj"
  instruction on my part, just noting it for the record.
